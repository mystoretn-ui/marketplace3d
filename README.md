# Marketplace3D

A MakerWorld-inspired 3D model marketplace.

## Features
- Login / registration / logout
- User profiles and portfolios
- Upload STL, OBJ, 3MF, ZIP and images
- Free or paid models in USD
- 19% marketplace commission
- Search, categories, favorites, likes, comments
- Designer earnings and purchase history
- Admin-ready API structure

## Run
npm install
npm start

Then open http://localhost:3000
